# v0.17 Port — June 2026

Upstream baseline: `v0.17.0` release (`2bd1977d8`, 2026-06-19).
Port branch: `rebase/v0.17-port`, local head commit `1f1070538`.

This document records the local fork patches forward-ported onto upstream
v0.17.0. Each entry states the intent, user-visible impact, touched areas,
and verification status.

## Method

The previous local `main` (`aacecb03f`, built on the pre-v0.17 fork line) was
reviewed patch by patch against v0.17.0 source. Each patch was classified as
OBSOLETE (upstream already solved it), DROP (no longer relevant), KEEP-ASIS
(direct transplant), ADAPT (needed modification), or REWRITE (v0.17 has a
better approach). Only the non-obsolete patches were carried forward.
